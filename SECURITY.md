# Security reporting

Use this repository's GitHub **Security → Report a vulnerability** feature when
available. Do not post credentials, private source content, personal notes or an
active exploit in a public issue. Include the affected version, a synthetic
reproduction, expected permissions and the observed impact.

The supported development line is the current main branch. The web surface is
read-only and loopback-bound; there is no remote administration or trading API.
Public hosting still requires an operator to manage edge policy, runtime updates
and access controls. Browser notes are local to an origin and are not encrypted
against other users of the same browser profile.
