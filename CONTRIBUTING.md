# Contributing

Use a branch and pull request against this repository. Include the concrete
behavior change, relevant validation and remaining limitations. Keep changes
focused; preserve live permission checks and the separation between engagement,
recognition and evidence of trading performance.

Run the tests listed in README. Use synthetic fixtures, never production captures
or personal notes. Collection tests must remain offline. Do not add credentials,
source corpora, deployment reports, machine addresses or private configs even if
they appear in a local ignored directory.

Contributions are accepted under AGPL-3.0-only. Confirm you have the right to
contribute your code and examples. Third-party material requires compatible rights
and attribution; public visibility alone is not permission to redistribute it.

Report security issues privately using SECURITY.md. Do not add a live exploit,
secret or user data to a public issue.
