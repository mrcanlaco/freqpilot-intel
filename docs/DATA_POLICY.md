# Data and licensing boundaries

This public repository distributes software and synthetic test fixtures. It does
not distribute the hosted service's source corpus, database, raw captures, trader
reports, private plans or machine-level operational history.

The software license does not cover third-party content or grant access rights.
Before configuring a source, review its terms, access policy and redistribution
permissions. Use official APIs/exports when authorized. Respect robots policy,
login boundaries, rate limits, CAPTCHA and persisted Retry-After/cooldowns. Do not
switch accounts, IPs, proxies, locales or executor nodes to evade a block.

Keep observed performance evidence, operator captures, author self-claims,
recognition and engagement at their actual trust levels. Preserve provenance,
periods, timestamps and missing fields. No amount of follower engagement or an
influence award establishes audited trading skill.

Personal research lives in the user's browser. Private JSON/Markdown exports may
contain their notes and should not enter Git. A hostname change creates a separate
browser origin; use explicit export/import while the previous origin is reachable.

The default source lists are empty and collection is disabled. Example files
contain configuration shapes, not a licensed dataset or proof of source access.
Only complete, operator-reviewed publication bundles should be placed in local
`artifacts/`; they remain excluded from the public source repository.
